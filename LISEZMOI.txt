CycloPass API
=============

Pour lancer : python app.py

Ça tourne sur le port 5000.

Mise en production (procédure de Julien, à faire le vendredi soir) :
1. se connecter en SSH sur le serveur prod (mot de passe dans le carnet du bureau)
2. copier app.py avec scp dans /opt/cyclopass/
3. pip install des librairies si ça plante
4. tuer l'ancien process (kill -9) et relancer python app.py avec nohup
5. vérifier que ça répond, sinon remettre l'ancien fichier (s'il a été gardé)

Pas de tests. Pas de recette. Si un client appelle, prévenir Julien.
